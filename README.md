# Grains of Chance

Every grain of rice is one possible outcome and exactly one is gold. Pick a gamble (coin flip up to Powerball), try to tap the gold grain, see what a lifetime of playing gets you, and run a slot machine 100,000 times to watch the house edge win.

**Live:** https://caselka.github.io/grains-of-chance/

One self-contained `index.html`. No build step, no libraries. Open the file or visit the link.

Part of Abstract Projects: small interactive pages that make abstract ideas something you can poke at.
